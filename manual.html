0単位と記号

長さ

ワールド 1 単位 = 1 m。魚の全長は cm。水深 m。

時間

式の dt は実時間の秒。実 1 秒 = ゲーム内 1 分（1 時間 = 実 1 分、1 日 = 実 24 分）。

0〜1 の量

テンション比と体力は 0〜1 の内部値、残り距離は実際のメートル。画面に出るのはテンションのバーだけで、距離と体力は内部値のまま（下の 1 章参照）。

以下、sp は魚種データ、rod/line/bait は装備データ、F はファイト中の状態を指します。

1ファイト — 4つのメーターの正体

ヒット後の駆け引きは、次の 4 つの状態量だけで決まります。毎フレーム、この 4 つが更新され、 3 つの終了条件のどれかに触れた瞬間に決着します。

ただし画面に出るのはラインテンションのバーだけです。 表示は「テンションだけ」と「なし（竿と音だけ）」の 2 択（U で切り替え）で、 残り距離・魚の体力・手応えの見出しを並べた従来のパネルは廃止しました。 数字が 3 本並ぶとそれを読む作業になり、竿のしなり・ドラグ音・水面の様子を見なくなるためです。 距離と体力は内部では今までどおり効いていて、寄っている感じは竿の角度と魚の見た目、 弱ってきた感じは浮いてくる魚と引きの軽さで分かります。

ラインテンション

F.tension / line.cap

糸に掛かっている張力。巻くと増え、離すと減る。line.cap（糸の強さ）に達した瞬間にラインブレイク。
警告（バーの点滅・画面端の赤）はテンションの % ではなく「切れるまでの残り秒数」で出す （SNAP_WARN_LEAD = 1.5 秒前から）。張力の上がる速さは魚 × サイズ × 竿 × 糸で 2 倍以上変わるので、 % 固定だと猶予が揃わない（旧方式の実測：80% から切れるまで通常 0.4〜0.6 秒、 突進中はどれも 0.26〜0.32 秒しかなく反応できなかった）。 残り秒数で出すと猶予がどの相手でも 1.5 秒に揃い、警告が始まるテンションは相手によって自動的に変わる （実測：通常 68〜77% / 突進中 45〜55%）。
さらに張力の上下そのものを TENSION_TEMPO = 0.5 で半分の速さにしてある（上がる・戻る・突進中の押し戻しを同じ倍率で遅くするので 押し離しの比率＝難易度は保たれ、テンポだけ落ちる）。ゲージが 0 から満タンになるまで約 4〜5 秒。

残り距離 （非表示）

F.dist（実際のメートル）

魚までの距離（m）。ヒット時は掛けた距離そのままで始まり、巻けば減り、放せば魚に引かれて増える。掛けた距離＋16m（糸の 62m 上限まで）で逃走／0.7m まで寄せ、かつ魚が水面から出たら取り込み。近くに掛ければ寄せる距離も短い。

魚の体力 （非表示）

F.stamina（1 → 0）

魚のスタミナ。テンションを掛けている間だけ減る。減ると引く力が弱まり、突進しなくなり、水面に浮いてくる。

突進（ラン）

F.running / runTimer

周期的に発生する暴れ。発生中は引く力が 2 倍。「走った！」の表示中に巻くと一気にテンションが上がる。

細かい連打は空回りします。巻き取りには立ち上がり（F.spin）があり、押し始めは 0、 押し続けて 0.22 秒で 63%・0.66 秒で 95% まで乗ります。離すと 0.12 秒の時定数で落ちます。
40ms 間隔で叩くと乗りは 30% 前後で止まるので、同じ時間押し続けた場合と比べて巻き取りは 1/3 程度。実測（カーボン+PE・同じ 1 匹）：連打 2.6 秒で −0.24m（＝逆に出された）／押し続け 2.6 秒で +7.32m。
慣性のぶん全体が間延びしないよう、巻き取りの基準速度は 4.2 → 4.6 m/s に上げています。
引きの強い魚は長く押せない（すぐテンションが上限に来る）ので乗り切らず寄せられない—— これが装備の壁として効きます。逆に弱い魚は長く押せるので慣性はほぼ影響しません。
乗りは専用のバーを出さず、ファイトパネルの表示（巻き始め… → 巻いている）と リール音の変化で伝えています（メーターを増やすと画面が煩雑になるため）。
なお張力を見ずに一定間隔で叩くだけでは上限を超えて切れます （実測：チョウザメ平均 123cm・竹+ナイロンで、押 0.15〜0.80 秒／離し 0.15〜0.80 秒のどの組み合わせでも 100% ラインブレイク）。 テンションを見ながら間隔を合わせられる人だけ、初期装備でも大物を獲れます。
張力の増え方は立ち上がりに依存させていません。依存させると「連打すると張力も上がらない＝ 高い張力を保ったまま巻き比率を上げられる」ことになり、かえって連打が有利になりました （実測：張力を spin に比例させると連打の所要時間が 181 秒 → 59 秒に短縮）。
ファイト中の見た目：糸は竿先から魚の口（ローカル +X が頭なので +0.48 × 全長 の点）に付き、 ウキはその糸が水面と交わる位置に置きます（たるみ込みの曲線で二分探索するので、見えている糸の上にちょうど乗る）。 魚が跳ねて糸が水面と交わらないときはウキも口の位置へ。取り込み中も口から下がります。
ファイトパネルの案内文は出しません（操作は 2 つだけなので、状態は見出しの 「跳ねた／首を振っている／走っている」で足りるという判断）。

ファイト中は魚種とレア度を伏せています。以前は pull0（= 種の str × サイズ係数）から 「軽い引き／強い引き！／とてつもない重さ…！」という手応えの見出しを出していましたが、 パネルごと廃止しました（手応えは竿のしなりと巻きの重さで伝わるため）。 pull0 自体は残っていて、ヒット時のメッセージ・突進の警告・エラ洗いの発生は レア度ではなくこの値を基準にしています。

ファイトの型（魚種ごとの振る舞い）

魚種には fight で 型が1つ割り当てられています。型は上の更新式に掛ける倍率と追加イベントだけで、 新しいメーターや操作は増えません（1.0 なら従来と同じ挙動）。 fight が無い魚種は fightPattern() がタグ・体型から自動で決めます。

ジャンプの扱い

ジャンプは突進の途中で発生し、跳ね終わるまで突進が終わりません。 つまり「走ったら糸を送る」という基本ルールを守っていれば自動的に対応できます。 送れていれば魚が余計に消耗し（jumpDrain /秒だけ体力が減る）、 巻いたままだと張力の増加が jumpTension 倍になります。

首振りの扱い

数値そのものを揺らすのではなく、振っている間だけ巻き取り効率が shakeReel 倍に落ち、張力の増加が shakeGain 倍になります。 メーターは正直な値のままなので「振っている間は手を止める」という判断が生まれます。

型はレア度が偏らないように割り当てています（各型にコモン〜レア以上が混在）。 ファイト中に型が分かってもレア度や魚種は特定できません。

質問への回答

Q. 「魚の体力」とは？ 減ると何が起きる？ 魚のスタミナ F.stamina（1 → 0）です。テンションを掛けている間だけ削れ、 減ると次の 3 つが同時に起きます。
  • 引く力が落ちる：pull の係数 (0.5 + 0.5×stamina) が 1.0 → 0.5 に。つまり最大で半減。 引きが弱まると resist が上がるので巻き取り速度も上がり、加速度的に楽になります。
  • 突進しなくなる：stamina ≤ 0.16 で新しいランが発生しません。
  • 浮いてくる：見た目の泳層が lerp(0.4, 掛けた深さ, stamina²) と浅くなり、水面で暴れる演出になります。
減る速さは ÷ max(0.4, sp.sta)。つまり sp.sta（体力値）が大きい魚は「粘る」＝弱らせるのに時間が掛かります。 テンション比 0.7 を維持した場合の目安は (0.022 + 0.7×0.17 + 0.02) / sta ≒ 0.16 / sta /秒 → sta 1.0 の魚なら約 6 秒、sta 3.2 の湖の主なら約 20 秒でスタミナ切れ。 逆にテンションを掛けずに待っても魚は疲れません（0.022/sta しか減らない）。

水面から出るまで巻く

取り込みは残り距離だけでは決まりません。実際の取り込みと同じで魚が水面から出ることが条件です （魚の深さ <= 0）。これが無いと、桟橋の深穴で真下に掛けた魚が 水深 10m のまま「釣り上げた」ことになってしまいます（水平距離だけを見ていたため）。 

// 体力から決めた泳層を、寄せるほど水面へ引き上げる。最後の目標は水面より上
riseFrom  = clamp(wantDepth * 1.1, 2.5, 12)   // 深い魚は早めに、浅い魚は直前から上がる（≒45度）
wantDepth = lerp(−0.12, wantDepth, clamp01((F.dist − 0.7) / riseFrom))   // −0.12 = LAND_LIFT_M

// 実際の Y は damp。ただし浮き上がる速さに上限を掛ける
ny = damp(魚.y, 水面 − wantDepth, 目標が上なら 5.5 / 下なら 2.4, dt)
魚.y = min(ny, 魚.y + 3.0 * dt)   // RISE_MPS：水面へ飛び出すのを防ぐ

Q. ラインの「素材 × 号数」って何が変わるの？ ラインはナイロン／フロロカーボン／PE の3 素材 × 1〜3号の 9 種類。号数は同じ素材内の強度の階段 （1号<2号<3号）だけを動かし、素材が強度以外の性格（一長一短）を決めます。
  • cap（強さ＝切れる張力）：ナイロン1号 0.72 〜 PE3号 3.11 まで、号数と素材の両方で伸びる （1号<2号<3号 かつ ナイロン<フロロ<PE）。
  • line.shock（テンションの増え方の倍率）：ナイロン 0.90（伸びが衝撃を逃がすので上がりにくい＝寛容） → フロロ 1.00 → PE 1.10（伸びがほぼ無く直に伝わる＝やや厳しい）。張力の増加は (0.08 + pull×0.55) × line.shock / rod.power /秒なので、PE は cap こそ高いが上がる速さも速い ——強い代わりに雑に巻くとすぐ切れる、という一長一短。
  • line.attract（アタリまでの速さ）：見えにくいフロロが最速、ナイロンは標準、 目立つ PE はやや遅い（フロロ>ナイロン>PE、2号基準で 1.15 / 1.00 / 0.88）。 同じ素材でも号数が細いほど速い（1号>2号>3号）——太いほど目立って遅くなる。
  • line.biteWindow（アワセ猶予）：伸びないぶんアタリが直に伝わる PE が 1.2 で最長、 ナイロンは 0.85 で最短、フロロは 1.0（標準）。
Q. ロッドの「飛距離（cast）」「竿の力（power）」「巻取（reel）」の違い？ cast は狙える最大距離（m）そのもので、竹 10 → グラス 38 → カーボン 52 → 名匠 68 → 伝説 84。 初速の上限はこの値から弾道で逆算されます。最初の竹竿は意図的にごく短く、ほぼ足元しか狙えません。 岸沿いの水深は距離とともに伸びていく（38 m で中央値 約8 m、65 m で 約19 m）ので、中層〜深場・深淵は 竹竿では基本的に手が届かず、より長い竿を買って初めて狙えるようになります。
最弱キャスト（約1.7 m）も竿によらず同じなので、足元狙いが不利になることはありません （むしろ竹竿は「足元しか狙えない」竿なので、この短さそのものが個性です）。
桟橋の先端は元々「先端だけで深場が狙える」設計（水深 6〜19m）の構造物なので、竹竿でもそこから わずかに投げれば中層〜深場に届くことがあります（実測：ほぼ確実に深場止まり、深淵まで届く湖は 2%程度）。深場の魚を安定して狙うにはレベルによる解禁も必要です。
power はテンションの増加を割り算で抑える値（＝竿が引きを吸収する）で、tension += … / rod.power。 reel は巻き取り速度の倍率で、dist -= rod.reel × 4.6 × resist × (1+dist×0.012) × F.spin × dt（m/s）。 power は「切れにくさ」、reel は「早さ」に効きます。ラインブレイクを減らしたいなら line.cap と rod.power、 ファイトを短くしたいなら rod.reel です。attract はファイトには無関係（アタリの速さと抽選）。
power はもう一つ効きます：張力の増えが遅くなる＝長く押していられる＝リールが乗る、という経路です。 チョウザメ（平均 123cm・60 回試行）を連打で獲ろうとすると、伝説+PE3号でようやく獲れる（60/60・約 143 秒）だけで、 竹+ナイロン2号・グラス+フロロ2号・カーボン+PE2号はどれも 0/60。
同じ相手を警告どおりに離す操作なら、竹+ナイロン2号 2/60 → グラス+フロロ2号 59/60（約 31 秒）→ カーボン+PE2号 60/60（約 22 秒）→ 伝説+PE3号 60/60（約 12 秒）と、装備が素直に効きます。 つまり連打は装備が揃っていても損で、テンションを見て離すのが唯一の正解です。
逃走は「掛けた地点より 16m 走られる」ことで起きます。 放している間、距離は pull × 0.70 m/秒で増えます。強い魚の突進中（pull が 2 倍）は 放すだけで毎秒 4m 以上取られることもあり、巻き取り（rod.reel×4.6×resist×F.spin）が それを下回る装備だとどう操作しても逃げられます。これが装備の壁です。

タナ（狙う層）を決める — 生息水深 × 遊泳層

魚のデータは2 軸に分かれています。 生息水深（depth）はその魚が居る場所の水深、 遊泳層（layer）は水中のどの層で食うかです。 プレイヤーは E の仕掛けウインドウで 表層／中層／底層 の 3 択を選び、 抽選では「その場所の水深が合っているか」×「その層で食うか」の両方が掛かります。

なぜ 2 軸なのか

時間帯で釣れる深さが変わる（日周移動）

現実の湖では、多くの魚が1 日のうちで泳ぐ深さを変えます。代表的なのは 日周鉛直移動（diel vertical migration）で、動物プランクトンが昼は捕食者を避けて深みに沈み、 夜に浮上するのに合わせて、それを食べる魚も同じように上下します（ワカサギの氷上釣りで 「昼は底、朝夕は浮く」と言われるのはこれ）。ほかにも

  • 朝夕のマズメ：鱒類・ブラックバスは水温と光量が落ちる朝夕に浅い層へ差して水面を意識し、日中は深い層・カバーの底に落ちる
  • 夜の接岸：ナマズ・ウナギ・コイ・エビ・カニは夜になると浅場へ出て餌を探し、日中は深場の底や穴に潜む
  • 逆パターン：ライギョは変温動物で日中の高水温を好み、昼に水面のカバーで浮いている。夜は沈む
  • 朝夕の待ち伏せ：イトウは朝夕に浅場の表層で待ち伏せ、日中は深場の底へ落ちる

実装は 2 つの入口を用意しています。層が入れ替わる魚は layer を時間帯ごとの表にし、 浅場と深場を行き来する魚は diel（−1 で浅場寄り 〜 +1 で深場寄り）で 生息水深の帯そのものを上下させます（ずれ幅は帯の 35%）。両方持つ魚もいます。

5キャストの物理

キャストは「狙った距離に当てる」操作です。視線が水面と交わる点が狙い点で、そこに水色の輪が出ます。 メーターの緑の帯はその距離に必要なパワーの位置。帯の中で離すと狙い通りに落ちます。

棚とかけあがり（階段）

湖底の深さを「なめらかな斜面 30〜40%」＋「2〜4 段の落ち込み」に分けて作ります。 段のあいだは平らな棚になり、段の所だけ急なかけあがりになります（冪関数だけだとどこも同じ傾きで、平場ができませんでした）。
実測（水深 1.5〜8m）：傾き 0.12 以下が 23〜30%（＝棚）、0.30 以上が 46〜52%（＝かけあがり）。 断面の例：0→1.3m の浜 → 1.2m の棚が 8m → 6m で 5.8m 落ちる → 7.5m の棚が 12m 以上。
段の数は方角ごとに 2〜4 段ですが、3・4 段目は 0 から連続的に立ち上げるようにしています（整数で切り替えると方角の境目で深さが飛び、湖底が扇状に割れて見えました）。

底質

砂地・岩場・泥底の 3 種。底を釣るときだけ強く効きます（中層 0.35 乗・表層 0.1 乗）。 岩場はバス・ライギョ・鱒、泥底はコイ科と底物、砂地は底物と深場の魚に向きます。
湖底には種類ごとのタイルテクスチャ（砂紋・転石・泥）を貼っており、水中カメラ（V）で見た目でも区別できます。 加えて岩場には転石が 600〜2400 個（描画品質で変わる）散らばります。 砂地との境は底質の値でまばらにし、斜面ほど深く埋めて浮いて見えないようにしています。

歩ける範囲

地形高さ −0.55 m まで（水深 0.55 m まで）入れます。勾配 1.5 超の急斜面は登れません。中心から 460 m が世界の端。

骨組みと姿勢

キャラクターは 62 本のボーンでリグ済み、24 種のアニメーション付きです。 ただし釣りの動作は入っていないので、脚と体はアセットのアニメーション・腕は計算で分担しています。 

// 毎フレームの順番
1. mixer.update()          // Idle_Neutral と Walk を moving の重みで混ぜる（脚・体幹）
2. 前傾と首の向き           // 腰を軸にした包みのグループと Head ボーン
3. 右手の位置を決める        // 右肩 + 姿勢ごとのオフセット
4. ロッドをそこに置く        // グリップの握り位置が手に来るよう、竿の向きに沿って戻す
5. 両腕を逆運動学で通す      // 肩→肘→手首の 2 リンク
6. 手首を竿の向きへ・指を握らせる
7. 竿のしなり（_applyBend）

src/angler.js — update(), _poseUpper(), _solveArm(), _aimBone()

どのボーンも +Y に伸びている

このリグは子ボーンが必ず親のローカル +Y にあります。 つまり「+Y を狙いの向きに合わせる」だけでどのボーンも向けられるので、 ボーンごとに回転軸を調べる必要がありません（_aimBone）。

ロッドは手のボーンの子にしない

手に付けるとリグの癖がそのまま竿の角度に乗り、 狙いの計算まで動きます。root に直付けして、毎フレーム「手の位置」と「設計どおりのピッチ」で置くことで、 竿の角度は姿勢ごとの設計値のまま・位置だけ手に追従します。

アニメーション対象のボーンに角度を足してはいけません。 three.js の AnimationMixer は値が前フレームと変わらなければシーングラフに書き戻しません。 そのため bone.rotation.x += 前傾 と書くと戻されずに毎フレーム積み上がり、 数十フレームで体が折れ曲がります（実際にそうなりました）。 いまは前傾をmixer が触らない包みのグループで作り、首は足さずに毎フレーム決め打ちで入れています。

竿のしなりを保つ

アセットの竿は 1 枚の固いメッシュなので、そのまま使うとしならなくなります。 ファイトの手応えはしなりで見せているので、読み込み時にボーンを自動で仕込んでいます。 

// 1. モデルの上下端をしなりのボーン列に合わせて拡大・移動する（全長 6〜8m のものもある）
s = (穂先 − グリップ尻) / (モデルの上端 − 下端)
o = 穂先 − モデルの上端 × s

// 2. 高さから skinIndex / skinWeight を作る（関節 i と i+1 で線形に混ぜる）
関節 i の高さ Y[i] ≤ y < Y[i+1] のとき
  skinIndex  = (i, i+1)
  skinWeight = (1 − t, t),  t = (y − Y[i]) / (Y[i+1] − Y[i])

src/angler.js — setRod(), _weightRod()

関節の数（6）と長さは自作時代と同じなので、しなりの計算（1 章の _applyBend）はそのまま動きます。 グリップより下の頂点は根元のボーンに重み 1 で固定されるため、握りとリールは曲がりません。
