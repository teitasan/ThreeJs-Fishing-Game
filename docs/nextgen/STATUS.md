## 残っている問題

- **high 1440p の目標 p95 ≤ 16ms は未達**（正午 18、夜明け 21）。残りの大きい項：不透明 8ms（森 1.3・草 1.1・水辺の草 1.0・
  地形 1.7・残り 1.0）、反射 2.8ms（森 0.6・水辺の草 0.6・地形 0.4）、post 2.3ms（Bloom 0.7・SMAA・FINAL）、
  prep 1.5ms（水の FFT 0.5・空 0.3–0.5）。夜明けは近景の影が 1.5–1.9ms（低い太陽で影の投げ手が増える）。
  次の手：反射で森・水辺の草をさらに粗く、FFT を隔フレーム、Bloom の最初の段を FINAL に融合、夜明けの影の範囲
- mid の夜明けの GPU が 13.2–13.8ms（目標 13）。p95 は CPU 側の揺れで 16–20ms の外れ値が出る回がある
- 撮影の世界は `bootGame({quality})` だと起動ごとにシードが変わる（撮影表どうしで比べにくい）。`bootQuality` は既定のシード
- 雨の夕方（18.5h）の森と桟橋は暗い（読めるが黒に近い）。縞は直したが、見た目の明るさは post のグレードの調整が要る
- 水中：遠い湖底のギザギザの塊・白い縁のプランクトンは既定のシードの構図で再現できず未確認。魚が暗い影に見えるのは
  fish.js（変更禁止）の材質と水中の距離の減衰による
- 夜明けの水面の映りで、近い岸の森が黒く硬い縁で写る（反射 RT 0.5 倍の解像度と、下から見た樹冠の暗さ）
- 撮影のシナリオによって（`?gpuTimer=sync` なし）桟橋の床板に暗い縞が出る回がある（HEAD でも同じ。原因未調査、濡れの状態か影）
