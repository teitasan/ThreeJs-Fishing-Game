## 設計の決定

- **1 枚のパッチ + インスタンス**：インスタンス = (x0, z0, 格子の間隔, 段)。«親の 1/4 を親の細かさで» 描く区画は格子の間隔を子の段・段を親にして
  VS が 2 格子ごとに丸める（1 枚で済む）。距離は xz の 2 次元（カメラの高さ dy は各段の範囲を √(r² − dy²) に縮める）。
  段 l + 1 のジオモーフを ρ_l + √2·s_l より外から始めるので、隣り合う段の頂点が必ず一致する（Node で水密を検査：T 字の隙間 0）
- 選択は prepare で 1 回、パスごとに視錐台と高さのピラミッドで詰め直す（主・影は同じ選択、反射は範囲 2 倍の粗い選択）
- 断片は `ngTerrainH` を呼ばない（高さは vNgWorld.y）。core の監査は «本文に名前が出るサンプラー» を数えるので、
  heightfield の GLSL から `ngTerrainH` / `ngDepth` の本体を外して断片に入れる → 断片のサンプラー 12（上限ちょうど）
- 配列 A は √(アルベド)：RGBA8 の線形だと林床（0.03〜0.1）に段が付くため
- **遠目の樹冠**（r2）：遠景の稜線と 180m より先の森は «葉 1 枚の色» ではなく樹冠の見かけのアルベド（影と隙間で ×0.7）と
  樹冠の BRDF（日向と影が画素の中で混ざる。光と視線が揃うほど明るい：direct × mix(0.48, 0.92, (V·L)³)、空の光 ×0.72）。
  farAlbedo は林床の層（林床・苔）の所を «森の色の塊» にする（木の本数に依らない。植林の暗い帯と広葉樹の斑は稜線と同じ式）
- 草地は湖畔の緩い所（汀線から 20〜55m・傾斜 < 25°）だけ。それより上と急斜面は林床（日本の山は森に覆われる）

## 地面の種類（coverRules の `ngGroundKind(p)`）

一番重い層 + 1：1 林床・2 苔・3 草地・4 玉石・5 砂・6 泥・7 岩・8 踏み跡（0 = 不明）。p.y < 0 は湖底（4/5/6/7 が底質 = lake.bedAt）。
groundcover は自分のシェーダに `services.terrain.coverRules` を連結して呼ぶ（heightfield の uniforms が要る）。

## 自己批評

### 0 巡（r2 の最初の撮影：r2-quick0・r2-dbg）

1. 地形の素材がリンクに失敗していた（`upland` を宣言の前に使用）→ 直した。Node の静的検査と lab の 3 段のリンクの検査を足した
2. 湖の向こうの斜面（250〜450m）が淡いカーキの草地・苔に見える（日本の山の湖に見えない）→ 草地を湖畔の緩い所だけにし、
   farAlbedo の林床を «森の色の塊» に、遠目の樹冠の BRDF を足した
3. 遠景の稜線が明るい黄緑（放射輝度 0.11）で空気遠近の青に負ける余地が無い → 樹冠の見かけのアルベドを下げ、樹冠の BRDF
4. 稜線の頂が «高さで白い岩» になってアルプスのように見える → 急な崖だけを岩に
5. 急斜面の露岩が森の中に白い崩落のように目立つ → 森の中の岩を 0.8 倍弱め、45° → 48° に

## 他への要望

- sky：稜線の «青い層» は媒質（ngBetaM・ngInscatterAmb）で決まる。スタブの媒質では 2km で b/g ≈ 0.95 に留まる
  （地形の側は暗い樹冠で内散乱が勝つようにした）。本物の sky で `terrain-link` の帯ごとの b/g を見てほしい
