## 設計の決定

- **1 枚のパッチ + インスタンス**：インスタンス = (x0, z0, 格子の間隔, 段)。段 l + 1 のジオモーフを ρ_l + √2·s_l より外から
  始めるので、隣り合う段の頂点が必ず一致する（Node で水密を検査：T 字の隙間 0）
- 選択は prepare で 1 回、パスごとに視錐台と高さのピラミッドで詰め直す（主・影は同じ選択、反射は範囲 2 倍の粗い選択）
- 断片は `ngTerrainH` を呼ばない（高さは vNgWorld.y）→ 断片のサンプラー 12（上限ちょうど。r3 でマクロを制御の配列の層 2 へ）
- 配列 A は √(アルベド)：RGBA8 の線形だと林床（0.03〜0.1）に段が付くため
- **遠目の樹冠**：180m より先の森と稜線は樹冠の見かけのアルベドと樹冠の BRDF（direct × mix(0.48, 0.92, (V·L)³)、空の光 ×0.72）。
  **r4：樹冠と遠景には鏡面を持たせない**（direct / 空の鏡面 × (1 − 0.9·樹冠) × (1 − 0.5·遠景)）
- 草地は湖畔の緩い所（汀線から 20〜55m・傾斜 < 25°）だけ。それより上と急斜面は林床
- **r4：地形は renderOrder 3**（森・岩・桟橋の後に描き、早期の深度で隠れた画素を捨てる。5 未満なので late 扱いではない）
- 異方性は段別（high 4 / mid 2 / low 1。1440p で 8 → 4 が 1.3ms）

## 地面の種類（coverRules の `ngGroundKind(p)`）

一番重い層 + 1：1 林床・2 苔・3 草地・4 玉石・5 砂・6 泥・7 岩・8 踏み跡（0 = 不明）。p.y < 0 は湖底（4/5/6/7 が底質 = lake.bedAt）。
±768m の分布（r4）：林床 91%・苔 5.4%・砂 1.1%・草地 0.7%・泥 0.7%・岩 0.7%。

## 自己批評

### r2 の巡（要約）
upland の宣言の順でリンク失敗 → 直して検査を足した／湖の向こうの斜面が淡いカーキ → 草地を湖畔だけに／稜線が明るい黄緑 →
樹冠の見かけのアルベドと BRDF／稜線の頂が白い岩 → 急な崖だけ／森の中の露岩が白い崩落 → 弱めた

### r4 の巡（r4-proof → r4-proof2）
1. **400m 先の森の斜面が灰色の禿げ山**（noon-shore・ridge）。読み戻すと黒いアルベドでも 0.03 の放射輝度が残った = 粗さ 0.9 の
   GGX が斜めの視線で 1/(N·V) に光る鏡面 → 樹冠と遠景の鏡面を消した（灰色の斑 0.05 → 0.019、緑み）。稜線にも同じ扱い
2. **遠目の樹冠が手前の木の 1.7 倍明るい** → 樹冠の色の地図の暗さ ×0.78 → ×0.62
3. **稜線の岩峰が白い**（双子の峰）→ 岩のアルベド 0.15 → 0.095（地衣類）、最大 55%
4. **高所（> 150m）の露岩が 20° から**で、木の無い灰色の斑の元 → 31° からに、森の中は半分
5. **玉石の浜が «石畳»**（天辺が平らで隙間が細い）→ 円の断面・太い隙間の砂（密度 0.88 → 0.76）
6. **遠い帯ほど青くない**（鏡面を消した後、2–2.9km の b/g が 1.3–2km より 0.03 低い）→ 2km より先の樹冠の彩度を 35% まで落とす
7. **重さ**：地形が森より先に描かれ、木の後ろの画素まで素材を計算していた → renderOrder 3（forest-floor 3.9 → 2.7ms）

残した物（自分の範囲の外か、次の巡）：乾いた浜の小枝の線がまだ長い／草地は一様（groundcover の草で埋まる前提）／
稜線の «赤い筋» は trees のスタブの幹。
